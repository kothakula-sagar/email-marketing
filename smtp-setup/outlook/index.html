Outlook and Microsoft 365 SMTP setup

Check Outlook.com and Microsoft 365 SMTP settings, STARTTLS and OAuth compatibility before sending.

Connection settings

AccountSMTP_HOSTSMTP_PORTEncryption
Outlook.comsmtp-mail.outlook.com587STARTTLS · SMTP_SECURE=false
Microsoft 365smtp.office365.com587STARTTLS · SMTP_SECURE=false

Authentication

This release supports SMTP username and password. Outlook.com documents OAuth2 for SMTP, so direct Outlook.com sending is unsupported. Microsoft 365 works only if your organization permits password-based SMTP submission for that mailbox. App passwords do not provide OAuth.

Save your settings in .env, then restart the app. See the Windows setup guide.

Troubleshooting

  • Ask your administrator what authentication your tenant permits.
  • If you see an authentication rejection, check mailbox and tenant policy with your administrator.
  • Use an approved password-compatible mailbox or relay when OAuth is mandatory.
