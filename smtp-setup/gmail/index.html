Gmail SMTP setup

Set up Gmail SMTP with an eligible Google app password in Email Campaign Studio.

Connection settings

AccountSMTP_HOSTSMTP_PORTEncryption
Gmailsmtp.gmail.com587STARTTLS · SMTP_SECURE=false
Gmailsmtp.gmail.com465Implicit TLS · SMTP_SECURE=true

Authentication

Use your full Gmail or Google Workspace address for SMTP_USER and SENDER_EMAIL. Turn on 2-Step Verification and create an app password if the Google account or administrator allows it. Use the app password as SMTP_PASS.

Save your settings in .env, then restart the app. See the Windows setup guide.

Troubleshooting

  • If app passwords are unavailable, confirm your account and administrator policy. Use a supported mailbox if yours requires OAuth.
  • If authentication fails, check that the app password is current and matches the account.
  • If the connection times out, check the matched port and TLS setting.
