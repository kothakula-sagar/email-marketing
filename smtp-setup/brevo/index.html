Brevo SMTP compatibility

Check Brevo relay settings and login-to-sender compatibility with Email Campaign Studio.

Authentication

Brevo documents this SMTP relay for transactional email. Use a Brevo SMTP key rather than your account password or API key. This app requires SENDER_EMAIL to match SMTP_USER. Accounts issued an autogenerated relay login that differs from the verified sender cannot use this release directly. Check that the message type is permitted by your Brevo account and use its marketing tools for marketing campaigns when required.

Save your settings in .env, then restart the app. See the Windows setup guide.

Troubleshooting

  • Use the exact SMTP login shown by Brevo.
  • Check SMTP key and IP authorization if authentication fails.
  • Confirm sender verification and the provider’s usage rules before sending.
