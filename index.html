Install on Windows

Allow a few minutes for first-time setup. You’ll need the outgoing mail settings and credentials for a mailbox you’re authorized to use.

  1. Open the project folder

    Install Node.js 22.12 or newer, extract the ZIP, and open the folder containing package.json. In File Explorer, press Alt+D, type cmd, and press Enter.

  2. Create and edit your settings file

    if not exist .env copy .env.example .env
notepad .env

    Enter your provider’s SMTP host, port, encryption setting, mailbox address and password. Replace the example sender, reply-to, unsubscribe, company and business address details with your own. Save the file and keep it private.

  3. Install dependencies and start the app

    npm install
npm start

    Keep Command Prompt open and visit localhost:3000 on that PC. When you see Mailbox configured, review your selected test recipients before sending.

Common questions

Is the app free?

Yes, the app is free to download and use. Any fees or sending limits depend on the mailbox provider you choose.

Where are my contacts stored?

Contacts, campaigns, and send history are saved in your local browser profile. Use the backup feature before switching computers or clearing browser data.

Does a ZIP download install the app automatically?

Extract the ZIP and follow the commands in the Windows installation guide to run the app.
