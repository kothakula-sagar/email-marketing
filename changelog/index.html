License

The download is offered at no charge. The repository does not currently publish a separate software license. Contact the maintainer through GitHub Issues about redistribution or reuse.

Privacy

The app keeps contacts, drafts and send history in your browser. When sending, your SMTP provider receives the recipient address and message. Backups are files you control. This website counts only download, setup-guide and GitHub clicks in local browser storage, with no external analytics service.
